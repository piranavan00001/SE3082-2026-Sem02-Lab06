Exercise 03: OpenMP Master Directive

Code:
#include <omp.h>
#include <stdio.h>

int main() {
#pragma omp parallel
{
  int th = omp_get_thread_num();
  printf("thread # %d\n", th);

 #pragma omp master 
 {
    printf("Inside Master # %d\n", omp_get_thread_num());
    printf("Exiting Master \n");
 }
 printf("Hi again from thread # %d\n", omp_get_thread_num());
}
   return 0;
}

Explanation:
The `#pragma omp master` directive ensures that the enclosed block is executed exclusively by thread 0 (the master thread). All other threads skip the master section. Unlike `#pragma omp single`, there is no implicit barrier at the end of `#pragma omp master`. Non-master threads immediately continue to the next statements without waiting for thread 0 to complete the master block.
