Exercise 02: OpenMP Single Directive

Code:
#include <omp.h>
#include <stdio.h>

int main() {
#pragma omp parallel
{
  int th = omp_get_thread_num();
  printf("thread # %d\n", th);

 #pragma omp single
 {
    printf("Inside Single # %d\n", omp_get_thread_num());
    printf("Exiting Single \n");
 }
 printf("Hi again from thread # %d\n", omp_get_thread_num());
}
   return 0;
}

Explanation:
The `#pragma omp single` directive specifies that the enclosed block is executed by only one thread in the team (whichever thread reaches it first). The other threads in the team skip executing the single section. By default, there is an implicit barrier at the end of the single block, so all threads wait for the thread executing the single block to finish before continuing to "Hi again from thread # <id>".
